# 图腾、催眠限制与皮物管理

## 反制图腾

图腾放在背包或副手即可生效；兼容接受该物品的 Trinkets 槽位。专用图腾各可成功阻挡 5 次，TSF 反制图腾可阻挡 15 次。耐久耗尽时消失。只有原本能成功的操作才消耗耐久，被阻挡的施术者进入 1 秒冷却。专用图腾优先于通用图腾消耗。

| 物品 | 保护效果 | 合成 |
| --- | --- | --- |
| 催眠反制图腾 | 阻挡手机催眠 | 玻璃、磁石、玻璃横排 |
| 附身反制图腾 | 阻挡附身之矛、夺舍之矛、史莱姆夺舍及进入他人空肉体 | 可可豆、树脂团、可可豆横排 |
| 皮物反制图腾 | 阻挡皮刀皮化 | 玻璃、末地之眼、玻璃横排 |
| TSF反制图腾 | 以上全部效果 | 三种专用图腾加钻石，无序合成 |

空肉体保留其背包和饰品里的图腾保护，主人进入自己的空肉体不扣耐久。拉链允许自愿穿入，不受图腾限制。此版本图腾为个人携带物品，尚无放置后的区域保护效果。

四种图腾模型分别位于 `assets/tsf/models/item/*_protection_totem.json`，暂时引用内置 `tsf:item/phone` 占位纹理。绘制后可把贴图放到 `assets/tsf/textures/item/`，再修改模型的 `layer0`。

## 催眠限制

保持原有对准 16 格内无遮挡玩家、长按使用手机 3 秒的催眠方式，持续 60 秒。手机中选择被自己催眠的玩家，点击「催眠限制」可分别允许或禁止移动、交互及物品栏操作、视角转向、聊天及原版发言命令。初始全部禁止。

调整限制需要目标在 16 格内且无遮挡。全部允许后，催眠关系仍保留至超时或主动解除，可以再次限制；形态切换和 TSF 操作仍受催眠状态限制。催眠结束、任意一方退出服务器时解除限制。聊天限制使用 Fabric 的消息事件，覆盖原版聊天、私聊、广播和动作消息；其他模组自行实现的通信方式取决于其是否使用这些事件。

## 皮物管理

手机中的「皮物管理」列出由内到外的皮物，以及背包中可替换的皮物。最外层用醒目颜色标记。选择背包皮物后点击「替换最外层」，只替换最后一层，内层保留，原外层退回背包；背包装满时掉落在脚下。也可直接脱下最外层。列表支持翻页。

`config/tsf-server.json` 新增 `maxSkinLayers`，默认 16，允许 1～64。可在模组菜单的服务端设置中修改，服务器上需要管理员权限。降低上限后，超出层数的外层自动退回背包或掉落，不会销毁；直接经 Trinkets 穿戴也受上限约束。
